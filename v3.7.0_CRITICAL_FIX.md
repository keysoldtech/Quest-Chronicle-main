# 🚨 v3.7.0 - CRITICAL ATTACK FIX

## The Problem:

**Server wasn't responding to attack requests!**

**Root Cause:** Server only looked for weapons in `player.equipment`, but weapon cards can also be in `player.hand`!

```javascript
// OLD (broken):
const weaponCard = Object.values(player.equipment).find(c => c.id === weaponId);
// Only checks equipment - misses hand!
```

## The Fix:

**Now checks BOTH equipment AND hand:**

```javascript
// NEW (working):
let weaponCard = Object.values(player.equipment).find(c => c.id === weaponId);
if (!weaponCard) {
    weaponCard = player.hand.find(c => c.id === weaponId);
}
```

**Result:**
- ✅ Finds equipped weapons
- ✅ Finds weapons in hand
- ✅ Falls back to unarmed
- ✅ Server responds!
- ✅ Dice rolls work!
