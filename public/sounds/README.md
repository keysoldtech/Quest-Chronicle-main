# 🔊 Sound Effects - Free Assets Needed

## Required Sound Files

Place free sound effect files in this directory:

### Combat Sounds:
- `attack.mp3` - Sword swing
- `hit.mp3` - Damage impact
- `miss.mp3` - Attack miss
- `critical.mp3` - Critical hit

### Magic Sounds:
- `spell-cast.mp3` - Spell casting
- `heal.mp3` - Healing effect
- `buff.mp3` - Buff applied

### UI Sounds:
- `button-click.mp3` - Button press
- `card-play.mp3` - Card used
- `level-up.mp3` - Level up chime
- `victory.mp3` - Game won
- `defeat.mp3` - Game lost

### Monster Sounds:
- `monster-hit.mp3` - Monster takes damage
- `monster-death.mp3` - Monster defeated
- `monster-spawn.mp3` - Monster appears

## Free Sound Sources:

1. **Freesound.org** - Creative Commons licensed
2. **OpenGameArt.org** - Public domain game sounds
3. **Zapsplat.com** - Free with attribution
4. **Mixkit.co** - Free sound effects

## File Format:
- MP3 or OGG
- Keep files under 100KB each
- 44.1kHz sample rate recommended

## Implementation:
The game will automatically use these files if present, with graceful fallback if missing.
